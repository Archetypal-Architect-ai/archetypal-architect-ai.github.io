# Start Here

This repository is the public Astro site for Archetypal Architect:

- Repository: `Archetypal-Architect-ai/archetypal-architect-ai.github.io`
- Production site: <https://archetypalarchitect.online>
- Primary public experience: the cross-linked wiki at `/wiki`
- Adult material: `/adult-archive` and `/adult/:id`, protected by an age gate
- Editor doorway: `/admin`, backed by Pages CMS and GitHub commits

## Read In This Order

1. `CURRENT_STATE.md` for the latest decisions, known gaps, and next action.
2. `THREAD_RECOVERY_SOP.md` for the safe workflow when continuing site work.

## Operating Principle

This is a public-facing knowledge architecture, not a private notebook. Write pages as a tour through the mythos and the work. Keep author instructions, provenance, uncertainty, and production notes out of visible public copy unless they are intentionally part of the entry.

The site is deliberately graph-shaped: use meaningful links between major plot points, characters, worlds, systems, philosophies, works, and media. Do not link every noun. Keep adult erotica behind the adult boundary, including links that cross from public entries into adult entries.

## Safe First Move

Before editing, read `CURRENT_STATE.md`, inspect `git status`, and confirm the change belongs in this repository. Do not copy manuscript text, private filesystem paths, credentials, or unpublished source material into the public repository.
